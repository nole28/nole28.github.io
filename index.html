BEHIND THE CODE

When a deleted account broke the chat

While working on Noyoo, I found that a conversation wouldn't open if the other user's account had been deleted.

The app was expecting profile data that wasn't there anymore. I changed the loading logic to handle missing accounts, so the conversation still opens and shows "Deleted Account".

Loading conversations

Each account has its own hidden-conversation state. When loading chats, Noyoo checks that state and skips a hidden conversation until another message arrives.

FirestoreChatRepository.swift · fetchChats()
let hiddenDocument = try await hiddenConversationReference(
    document.documentID
).getDocument()

let privateData = hiddenDocument.data() ?? [:]
let latestMessageId = document.data()["lastMessageId"] as? String ?? ""
let hiddenThroughId = privateData["lastMessageId"] as? String

// A hidden conversation stays hidden until a new message arrives.
if hiddenThroughId == latestMessageId {
    continue
}
