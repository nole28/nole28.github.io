02 / ChatSide
Active development

A messaging app focused on clean architecture and local persistence.

ChatSide is a SwiftUI messaging app built around a simple chat experience and a more deliberate architecture underneath it. Conversations and messages are separated behind a ChatService abstraction, dependencies are injected through the app environment, and local messages are persisted using an actor-backed store with Codable JSON, atomic writes, and iOS file protection.

The current interface includes conversation search, quick contacts, one-to-one messaging, timestamps, unread states, and optimistic message sending.

Next

Unit tests, richer message types, a remote backend, and continued exploration of secure messaging and end-to-end encryption architecture.
